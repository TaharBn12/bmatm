# 🍿 WatchTogether — شاهدوا معاً

موقع **مشاهدة جماعية متزامنة** بواجهة عربية احترافية (HTML/CSS/JS) مع **سيرفر Java** اختياري.

- **الصفحة الرئيسية** (`index.html`): منطقة إضافة رابط المشاهدة + إنشاء غرفة + الدخول بكود غرفة.
- **صفحة الغرفة** (`room.html`): مشغّل متزامن **بكل الحالات** + **دردشة في الأسفل** + قائمة المشاركين.
- عند نسخ رابط الغرفة وإرساله لصديقك → **يُطلب منه إدخال اسمه** قبل الدخول.

## 🚀 التشغيل السريع

### الطريقة 1 — سيرفر Java (موصى بها: صفحات + مزامنة في خادم واحد)

تحتاج **JDK 11 أو أحدث** فقط (لا Maven ولا Gradle ولا مكتبات).

```bash
cd watch_together/java-server
./build.sh          # أو: javac -encoding UTF-8 -d out src/com/watchtogether/*.java
./run.sh            # أو: java -cp out com.watchtogether.Main
```

ويندوز:
```bat
cd watch_together\java-server
build.bat
run.bat
```

ثم افتح: **http://localhost:8080**

الخادم يطبع كل العناوين المتاحة (localhost + IP الشبكة المحلية) فتستطيع إرسال الرابط
لصديقك على نفس الشبكة مباشرة. لتغيير المنفذ:

```bash
PORT=3000 java -cp out com.watchtogether.Main
```

> نقطة المزامنة: `ws://localhost:8080/ws` — الموقع يكتشفها **تلقائياً**، لا تعديل مطلوب.

### الطريقة 2 — استضافة عادية (cPanel / Netlify / GitHub Pages / Vercel)

1. ارفع **محتوى مجلد `watch_together/`** إلى `public_html` (أو اسحب المستودع في Netlify).
2. افتح Supabase → **SQL Editor** → الصق [`docs/schema.sql`](docs/schema.sql) → **Run**.
   > الملف آمن لإعادة التشغيل (`if not exists` + `drop policy if exists`)،
   > ولا يلمس مخطط `realtime` إطلاقاً.
3. انتهى ✅ — المزامنة والدردشة تعملان عبر Supabase Realtime بين كل المستخدمين.

تفاصيل أكثر: [`docs/supabase-setup.md`](docs/supabase-setup.md) و [`docs/deployment.md`](docs/deployment.md).

### الطريقة 3 — تجربة محلية سريعة بدون سيرفر

```bash
cd watch_together
python3 -m http.server 8080
```

سيعمل الموقع في **الوضع المحلي** (مزامنة بين تبويبات نفس الجهاز/المتصفح) — ممتاز لتجربة
الشكل والتدفّق، لكن للمشاركة بين أشخاص مختلفين استخدم الطريقة 1 أو 2.

## 🔌 أوضاع المزامنة (اختيار تلقائي)

| # | الوضع | متى يعمل؟ | ماذا يحتاج؟ |
|---|-------|-----------|-------------|
| 1 | **سيرفر Java** | فتحت الموقع عبر `java-server` | JDK فقط — مزامنة فورية داخل السيرفر |

الترتيب تلقائي: يحاول **Java** أولاً (مهلة 2.5 ث)، ثم **Supabase**، ثم **محلي**.
الوضع الحالي ظاهر دائماً في الشارة أعلى الصفحة وفي الشريط السفلي.

## ⚙️ ما الذي تتم مزامنته؟ (كل الحالات)

| الحالة | السلوك |
|--------|--------|
| ▶️ تشغيل / ⏸ إيقاف | يُبثّ فوراً للجميع |
| ⏩ تقديم / ⏪ ترجيع (10 ث) | يُبثّ مع الموضع الجديد |
| سحب شريط التقدم | مزامنة الموضع (يعمل باللمس والفأرة، RTL صحيح) |
| 🎞️ تغيير الفيديو | الجميع يحمّل الفيديو الجديد في نفس اللحظة |
| ⏱️ انحراف الوقت | تصحيح تلقائي: ناعم (سرعة 1.25×/0.85×) أو قفزة عند فرق > 3 ث |
| 🚪 دخول/خروج مشارك | رسالة نظام في الدردشة + تحديث قائمة المشاركين |
| 👑 غياب المضيف | يظهر زر «تولّي التحكم» لأي مشارك |
| 🔇 حظر التشغيل التلقائي | يظهر زر «اضغط للتشغيل» فوق الفيديو |
| 📴 انقطاع الاتصال | إعادة اتصال تلقائية بتراجع تدريجي + رسالة في الدردشة |
| 🔄 إعادة تحميل الصفحة | استرجاع الحالة المحفوظة (الموضع/التشغيل/الرابط) |

**الأدوار:** منشئ الغرفة = **مضيف 👑** يتحكم بالتشغيل. الباقون في **وضع المتابعة**
(أزرار التحكم مُبهَتة) ويمكنهم تولّي التحكم بضغطة واحدة. الصوت وملء الشاشة حرّان للجميع.

## 💬 الدردشة

- منطقة دردشة كاملة **أسفل صفحة الغرفة** مع رسائل النظام (دخول/خروج/تغيير فيديو).
- صور رمزية بالأحرف الأولى + لون ثابت لكل اسم + وقت كل رسالة.
- **إيموجي سريع**، روابط قابلة للنقر، مؤشر «يكتب الآن…»، عدّاد رسائل.
- `Enter` للإرسال، `Shift+Enter` لسطر جديد، حماية من الإغراق (400ms).
- على الجوال: زر دردشة عائم مع **عدّاد الرسائل غير المقروءة**.

## 🎨 التخصيص

كل شيء في ملف واحد: **[`assets/js/config.js`](assets/js/config.js)**

```js
supabase: { url: '...', anonKey: '...', ready: true },  // مفاتيح مشروعك
sync: { heartbeatMs: 4000, driftTolerance: 1.2, hardDrift: 3.0 },
chat: { maxLength: 600, cooldownMs: 400 },
room: { codeLength: 6 }                                  // طول كود الغرفة
```

والألوان في أعلى `assets/css/app.css` داخل `:root` (متغيّرات CSS — غيّر `--brand` و `--brand-2` فقط ليتبدّل طابع الموقع كله).

## 🔗 شكل رابط الغرفة

```
https://موقعك.com/room.html?id=8F3K2Q
```

- يفتح الرابط → نافذة **«أدخل اسمك للدخول»** → يدخل الغرفة مباشرة.
- إن كانت الغرفة تحتوي فيديو محفوظاً، يُحمّل تلقائياً عند نفس الموضع.
- أول شخص يدخل غرفة فارغة يصبح **المضيف** تلقائياً.
- يوجد أيضاً زر **QR** داخل الغرفة لعرض رابط الدعوة كرمز مربّع.

## 🛡️ ملاحظات أمنية

- المفاتيح في `config.js` هي **مفاتيح anon العامة** (مصمّمة لتكون في المتصفح) — لكن
  سياسات RLS في `schema.sql` مفتوحة (`anon`) لأن الموقع يعمل بالاسم فقط بدون تسجيل دخول.
  إن أردت تقييداً أقوى: أنشئ جدول `room_members` وطبّق `auth.uid()` في السياسات.
- سيرفر Java يرفض مسارات `../`، ويحدّ حجم رسالة WebSocket بـ 512KB، ويقفل الغرف الفارغة.
- لا تُخزَّن أي كلمات مرور؛ الأسماء تُحفظ محلياً في متصفح المستخدم فقط (`localStorage`).
