# النشر على Render — رابط عام دائم لمشروع WatchTogether

يحوّل هذا الدليل مشروعك من «سيرفر على جهازك» إلى **رابط عام على الإنترنت**
يخدم **الموقع كاملاً** (الصفحات + البحث + الاستخراج + مزامنة الغرف عبر WebSocket).

> Render لا يشغّل Java تشغيلاً أصلياً، لذلك نستخدم **Docker**: صورة واحدة فيها
> JRE 21 + Python + yt-dlp + ملفات الموقع.

---

## 1) ما الذي يُنشر بالضبط؟

| الملف | دوره |
|---|---|
| `Dockerfile` | يترجم مصادر Java، ثم يبني صورة تشغيل فيها Python و yt-dlp |
| `render.yaml` | مخطط النشر (Blueprint): الاسم، المنطقة، الخطة، المتغيرات |
| `.dockerignore` | يمنع رفع `.git` وملفات لا لزوم لها أثناء البناء |

كلها في **جذر المستودع** (بجانب مجلد `watch_together/`).

متغيرات التشغيل المهمة:

| المتغير | القيمة | السبب |
|---|---|---|
| `PORT` | `10000` | Render يمرّر منفذه تلقائياً، وهذه القيمة الافتراضية |
| `HOST` | `0.0.0.0` | الاستماع على كل الواجهات (إلزامي داخل الحاوية) |
| `ROOT` | `/app/watch_together` | مجلد الملفات الثابتة (الموقع) |
| `WT_PYTHON` | `python3` | اسم مترجم Python الذي يستخدمه `Py.java` |
| `PYTHONIOENCODING` / `PYTHONUTF8` | `utf-8` / `1` | يمنع «خدمة الاستخراج غير متاحة» مع العناوين العربية |
| `TZ` | `Africa/Algiers` | تواقيت صحيحة في السجلات |

## 2) الطريقة الأسهل: Blueprint (ملف واحد، بلا إعداد يدوي)

1. افتح <https://dashboard.render.com> وسجّل الدخول بحساب **GitHub**.
2. **New +** ← **Blueprint**.
3. اختر مستودع `TaharBn12/bmatm` ثم **Connect** (إن لم يظهر، اضغط
   *Configure account* وامنح Render صلاحية المستودع).
4. Render يقرأ `render.yaml` تلقائياً ويعرض خدمة باسم `watchtogether`.
5. اضغط **Apply**.

سيبدأ البناء — يستغرق **3 إلى 6 دقائق** أول مرة (تنزيل الصورة + ترجمة Java + تثبيت yt-dlp).

## 3) الطريقة اليدوية (إن لم ترد Blueprint)

**New +** ← **Web Service** ← اختر المستودع ← ثم:

| الحقل | القيمة |
|---|---|
| Runtime | **Docker** |
| Region | **Frankfurt (EU Central)** — الأقرب للجزائر |
| Branch | `main` |
| Instance Type | **Free** |
| Health Check Path | `/healthz` |

ثم أضف متغيرات البيئة من الجدول أعلاه في قسم **Environment**.

---

## 4) بعد النشر: تحقّق

رابطك سيكون: `https://watchtogether-xxxx.onrender.com`

من **CMD** على جهازك (بدّل الرابط برابطك):

```bat
curl https://watchtogether-xxxx.onrender.com/healthz
curl https://watchtogether-xxxx.onrender.com/api/stats
```

- `/healthz` يُرجع `ok` → الخدمة حيّة.
- `/api/stats` يُرجع إحصاءات الغرف والمنفذ وإصدار Python/yt-dlp.
- في السجلات (Logs) سترى لافتة عربية فيها سطر **الرابط العام** و**Python** و**yt-dlp**.

ثم افتح الرابط في المتصفح — يعمل الموقع كما على جهازك تماماً.

## 5) قيود الخطة المجانية (مهم)

| القيد | الأثر | التخفيف |
|---|---|---|
| **نوم بعد 15 دقيقة خمول** | أول طلب بعد النوم يستغرق ~50 ثانية | افتح الرابط قبل الاستخدام بدقيقة، أو ارقَ إلى خطة مدفوعة |
| **قرص مؤقت** | تُحذف `data/rooms.json` (الغرف) عند إعادة التشغيل/النوم | الغرف مؤقتة أصلاً؛ أو أضف قرصاً دائماً ( below ) |
| **0.1 وحدة معالج · 512MB رام** | الاستخراج (yt-dlp) أبطأ قليلاً | مقبول؛ الاستخراج يبقى تحت 40 ثانية |
| **حجب محتمل من يوتيوب** | عناوين مراكز البيانات كثيراً ما تُحجب: قد يفشل **بحث يوتيوب** أو **استخراج رابط يوتيوب** | تشغيل يوتيوب يعمل دائماً بالمشغّل الرسمي داخل `iframe`؛ وديليموشن يعمل عادةً |

### حفظ الغرف على قرص دائم (خطة مدفوعة)

1. من صفحة الخدمة: **Disks** ← **Add Disk** ← الاسم `data` والمسار `/var/data`.
2. أضف متغيراً: `JAVA_TOOL_OPTIONS = -Dwt.data=/var/data`
3. أعد النشر — تُحفظ `rooms.json` على القرص الدائم.

## 6) استكشاف الأخطاء

| العَرَض في Render | السبب | الحل |
|---|---|---|
| `Build failed` عند `javac` | خطأ ترجمة في المصادر | انسخ آخر أسطر الخطأ من سجل البناء وأرسلها |
| `Health check failed` | `/healthz` لم يجب خلال 45 ثانية | ارفع `start-period` في `HEALTHCHECK`، أو تأكد أن `PORT` مطابق لما يمرّره Render |
| `Application failed to respond` | `HOST` ليس `0.0.0.0` | تأكد من متغير `HOST` |
| الصفحة تفتح لكن «خدمة البحث غير متاحة» | yt-dlp غير مثبّت أو محجوب | Logs ← ابحث عن سطر `Python :` و`yt-dlp :`؛ أعد النشر لتثبيت أحدث إصدار |
| «طلب من مصدر غير مسموح» | فتحت الصفحة من رابط وطلبت الـ API من رابط آخر | Render يخدم الموقع والـ API من **نفس** الرابط — افتح كل شيء منه |

---

## 7) الأمان

- لا توجد أي مفاتيح أو أسرار داخل الصورة؛ كل متغيرات البيئة في `render.yaml` قيم عامة.
- نقاط `/api/*` ترفض الطلبات من مصادر غير مسموحة (نفس الأصل) — ولأن الصفحة
  والخدمة على الرابط نفسه، لا حاجة لأي قائمة مصادر.
- لتحديث yt-dlp على Render: **Manual Deploy** ← **Clear build cache & deploy**.
