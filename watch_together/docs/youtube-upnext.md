# «التالي» واستيراد قوائم يوتيوب

ميزتان تعملان **بلا مفتاح YouTube Data API وبلا سيرفر Java**، لأن الاستضافة ثابتة
(Supabase / GitHub Pages) ولا يصل المتصفح إلى `youtube.com` بسبب CORS.

الملفات:
- `assets/js/suggest.js` — محرك البيانات (توسيع القوائم + الاقتراحات + العناوين)
- `assets/js/upnext.js` — الواجهة (طبقة «التالي» + نافذة الاستيراد)
- `assets/css/suggest.css` — التنسيق (نفس لوحة Midnight Gold)

## 1) استيراد قائمة تشغيل

الصق في حقل «رابط الفيديو» أي رابط فيه `list=`:

| الرابط | السلوك |
|---|---|
| `youtube.com/playlist?list=PL…` | تُفتح نافذة الاستيراد بكل الفيديوهات |
| `youtube.com/watch?v=XXXX&list=PL…` | نافذة الاستيراد + زر **«الفيديو فقط»** |
| `youtube.com/watch?v=XXXX` | الإضافة العادية كما كانت |

ثم: حدّد ما تريد (الكل محدد افتراضياً) ← **أضف المحددة**.
تُضاف العناصر عبر الناقل نفسه (`addQueueItem`) فتصل لكل المنضمين كما لو أضافوها يدوياً.

- السقف الافتراضي: **60** فيديو (`youtube.maxImport`)
- الإضافة متسلسلة مع شريط تقدّم، وفشل عنصر لا يوقف البقية
- تُحفظ تركيبة القائمة في `wt:plctx:<roomId>` لتخدم الاقتراحات لاحقاً

## 2) طبقة «التالي» عند انتهاء الفيديو

عند انتهاء فيديو **يوتيوب فقط** (بقية الأنواع لا مقترحات لها):

1. تظهر طبقة فوق المشغّل باقتراحات «بحسب المحتوى».
2. أول مقترح يُشغَّل منه **معاينة صامتة** (10 ثوانٍ افتراضياً) مع حلقة عدّ تنازلي.
3. بعد انتهاء العدّ:
   - **المتحكم (المنشئ/المنظّم):** يكمل تلقائياً — يُضاف للقائمة ثم يُشغَّل للجميع.
   - **المشاهد:** يبقى الانتظار مع رسالة «بانتظار المنظّم…»، ويمكنه إضافة أي مقترح للقائمة.
4. تبديل الفيديو أو اختيار مقترح يُخفي الطبقة فوراً ويوقف المعاينة.

## كيف نحصل على البيانات بلا مفتاح ولا سيرفر؟

| الحاجة | الطريقة | البديل عند الفشل |
|---|---|---|
| توسيع قائمة | IFrame API: `loadPlaylist` + `getPlaylist()` | رسالة واضحة بأن القائمة خاصة/غير قابلة للتضمين |
| الاقتراحات | قائمة الميكس التلقائية `RD<videoId>` — نفس خوارزمية يوتيوب | أحدث فيديوهات القناة (`UU…`) ← مرايا اختيارية |
| العناوين والصور | YouTube **oEmbed** (يدعم CORS) + ذاكرة 7 أيام | `noembed.com` ← عنوان بديل فيه معرّف الفيديو |

ضوابط الأداء:
- **ميزانية زمنية واحدة ≈ 6 ثوانٍ** لكل المصادر، فلا ينتظر المشاهد مصدراً متعطلاً
- ذاكرة محلية للاقتراحات 6 ساعات (`wt:ytsug:<videoId>`) والعناوين 7 أيام (`wt:ytmeta:<id>`)
- مِسبار واحد مخفي وصغير الحجم يُدار تلقائياً ويُدمَّر بعد الاستخدام

## إزالة تحكم يوتيوب (التحكم من مشغّلنا فقط)

في `player.js` ننشئ مشغّل يوتيوب بـ:

```
controls:0  disablekb:1  fs:0  rel:0  modestbranding:1
iv_load_policy:3  cc_load_policy:0  playsinline:1
```

- لا أزرار ولا اختصارات لوحة مفاتيح ولا تكبير من يوتيوب (`fs:0`) — زر الغرفة يستخدم
  `requestFullscreen` على العنصر نفسه فلا يتأثر
- لا فيديوهات مقترحة من يوتيوب عند النهاية (`rel:0`) — بديلها طبقة «التالي» عندنا
- طبقة النقر الشفافة (`.vclicklayer`) تمنع نقر يوتيوب المباشر، فالتشغيل/الإيقاف
  والاختصارات كلها من شريط الغرفة

## الإعدادات (config.js → youtube)

```js
youtube: {
  previewSeconds: 10,   // مدة المعاينة قبل الإكمال التلقائي (3…30)
  suggestLimit: 12,     // أقصى عدد مقترحات
  maxImport: 60,        // أقصى عدد فيديو مستورد من قائمة
  oembedFallbacks: ['https://noembed.com/embed?format=json&url='],
  mirrors: []           // مرايا Piped/Invidious اختيارية عند الحجب
}
```

## الاختبار الآلي

`WTUpNext` و`WTSuggest` قابلان للاختبار بلا شبكة: استبدل `window.YT` بمُحاكٍ
يُعيد `getPlaylist()`، واستبدل `fetch` بمُحاكٍ لـ oEmbed، ثم حرّض `onEnded()`.
مثال جاهز: مسار الاختبار في الجلسة `wt-smoke/upnext.test.js` (32 تحقّقاً: كشف
الروابط، الاستيراد، العرض، العدّ، صلاحيات المشاهد/المتحكم، وإخفاء الطبقة).
