# البحث المتعدد + قائمة الانتظار

صفحة `/search.html` تضيف مساراً كاملاً: **ابحث (ديليموشن أو يوتيوب) ← اضغط نتيجة ←
إن كانت من ديليموشن يشغّل السيرفر yt-dlp ويعطيك رابط تشغيل مباشر ← شغّله،
أو افتح به غرفة، أو أضفه إلى قائمة انتظار غرفة موجودة.**

## المصادر

| المصدر | البحث | التشغيل |
|---|---|---|
| **ديليموشن** | `yt-dlp` بمستخرج `dailymotion:search` · بديله واجهة ديليموشن العامة | **رابط مباشر** من `/api/resolve` عبر yt-dlp، يُشغَّل في `<video>` |
| **يوتيوب** | `yt-dlp` بـ `ytsearchN:<كلمة>` — **بلا مفتاح API** | مشغّل يوتيوب الرسمي داخل `iframe` — **لا يحتاج استخراجاً** |

تبويبا المصدر أعلى الصفحة، والاختيار يُحفظ في المتصفح.

## قائمة الانتظار

- زر **«أضف إلى قائمة الانتظار»** في نافذة التشغيل يفتح قائمة غرفك.
- اختر غرفة → يُحفظ الفيديو في `sessionStorage` تحت `wt:pending-queue:<معرف الغرفة>`
  → تُفتح الغرفة → يستلمه `room.js` ويضيفه إلى القائمة عبر
  `addQueueItems()` (يعمل في الأوضاع الثلاثة: سيرفر Java، Supabase، محلي).
- **التشغيل التلقائي**: عند انتهاء الفيديو، إن كانت القائمة غير فارغة يشغّل
  **المتحكم** التالي منها ويزيله (`advanceQueue()` في `room.js`) قبل أن تتدخل
  طبقة الاقتراحات «التالي».

## 1) تجربة المستخدم

1. افتح `search.html` (أو زر **البحث** في الشريط السفلي).
2. اكتب كلمة البحث — البحث يجري تلقائياً بعد 700ms أو بالضغط على **بحث**.
3. النتائج شبكة بطاقات: صورة مصغّرة + مدة + عنوان + صاحب الفيديو.
4. اضغط أي بطاقة:
   - السيرفر يشغّل yt-dlp ويستخرج رابط تشغيل مباشر،
   - يُشغّل الفيديو فوراً في النافذة،
   - ويمكنك **فتح غرفة مشاهدة** به، أو **نسخ الرابط المباشر**،
     أو **فتحه على ديليموشن**.
5. كلمات البحث الأخيرة تُحفظ محلياً وتظهر كوسوم سريعة.

## 2) كيف تعمل التقنية

| الخطوة | من يقوم بها | كيف |
|---|---|---|
| البحث | السيرفر `/api/search` | `yt-dlp` بمستخرج `dailymotion:search` مع `--flat-playlist` (نداء بحث واحد) |
| تحسين النتائج | السيرفر | نداء واحد لـ `api.dailymotion.com/videos?ids=…` يجلب الأغلفة والمدة وصاحب الفيديو |
| بديل البحث | السيرفر | إن فشل yt-dlp → واجهة ديليموشن العامة (بلا مفتاح) |
| بديل الاستضافة الثابتة | المتصفح | إن لم يوجد سيرفر Java → المتصفح يستدعي `api.dailymotion.com` مباشرة (النتائج فقط) |
| **الرابط المباشر** | السيرفر `/api/resolve` | `yt-dlp -f "best[ext=mp4][vcodec!=none][acodec!=none]/best[vcodec!=none][acodec!=none]"` |

> لماذا `--flat-playlist`؟ البحث العادي في yt-dlp يزحف كل فيديو على حدة
> (20 نداءً)، أما المستوى المسرّع فيعطي المعرّفات والعناوين بنداء واحد، ثم
> نجلب الأغلفة والمدد بنداء واحد إضافي. النتيجة: بحث في ثانية تقريباً.

## 3) عقد النقطة `GET /api/search`

**الطلب**
```
GET /api/search?q=كلمة&limit=18
```
- `q` مطلوب، من حرفين إلى 80 حرفاً (تُنظّف من محارف التحكّم).
- `limit` اختياري، 1…24 (الافتراضي 18).

**الاستجابة (200)**
```json
{
  "query": "وثائقي",
  "source": "yt-dlp",
  "count": 18,
  "items": [
    { "id": "x8v9qk",
      "title": "…",
      "url": "https://www.dailymotion.com/video/x8v9qk",
      "thumb": "https://s1.dmcdn.net/v/…/x720.jpg",
      "duration": 745,
      "author": "…" }
  ]
}
```
`source` إما `yt-dlp` أو `dailymotion-api`.

**الأخطاء:** `400` كلمة قصيرة · `403` مصدر مختلف · `405` غير GET ·
`429` تجاوز الحد · `503` الخدمة غير متاحة — وكلها مع `items: []`.

**الحدود:** 20 بحثاً في الدقيقة، عمليتان متزامنتان كحد أقصى،
مهلة 30 ثانية لعملية yt-dlp و10 ثوانٍ لنداء واجهة ديليموشن.

## 4) المتطلبات

- **سيرفر Java شغّال** (`build.bat` ثم `run.bat`) — راجع
  `docs/java-server-windows.md`.
- **Python + yt-dlp**: `py -m pip install -U yt-dlp`.
  يُفضّل تحديثه دورياً: مستخرج البحث `dailymotion:search` أُضيف في
  yt-dlp منتصف 2024، وما قبله يعطي صفر نتائج (يعمل البديل مباشرة).

بدون السيرفر تعمل **النتائج فقط** عبر الواجهة العامة من المتصفح،
وتظهر ملاحظة تشرح أن استخراج رابط التشغيل يحتاج السيرفر.

## 5) استكشاف الأخطاء

| العَرَض | السبب | الحل |
|---|---|---|
| `0 نتيجة` دائماً | yt-dlp قديم أو البحث محجوب | `py -m pip install -U yt-dlp`، وجرّب `py -m yt_dlp --flat-playlist "https://www.dailymotion.com/search/كلمة/videos"` |
| النتائج بلا صور | تعذّر جلب الأغلفة | تظهر تلقائياً صورة ديليموشن الافتراضية `thumbnail/video/<id>` |
| `تعذّر استخراج رابط التشغيل` | yt-dlp غير مثبّت أو الفيديو محمي | راجع سطر `Python :` في لافتة السيرفر، وحدّث yt-dlp |
| الفيديو لا يعمل رغم نجاح الاستخراج | الرابط المباشر منتهٍ أو CDN يرفض CORS/Range | أعد المحاولة فوراً (الروابط مؤقّتة)، أو افتح الفيديو على ديليموشن |
| `429` | تجاوز 20 بحثاً/دقيقة | انتظر قليلاً |
| التبديل بين المصدرين لا يغيّر النتائج | بحث سابق كان لا يزال جارياً (حاجز `state.loading`) | مُصلَح: كل بحث يحمل رقماً مسلسلاً، والبحث الأحدث يُلغي نتائج الذي سبقه |
| «بحث يوتيوب يحتاج سيرفر Java» رغم أن السيرفر يعمل | `/api/search` لم يصل إليه المتصفح | الصفحة تُشخّص السبب الآن: `404` + `healthz` يستجيب = **سيرفر Java قديم** → `taskkill /F /IM java.exe` ثم `build.bat` و`run.bat`؛ `404` و`healthz` لا يستجيب = **هذه ليست صفحة سيرفر Java** → افتحها من العنوان الذي تطبعه لافتة `run.bat`؛ `503` = yt-dlp/Python معطّل؛ `file://` = تفتح الملف مباشرة |
| التبديل لا يظهر أبداً / التبويبان بلا تصميم | المتصفح يعرض نسخة قديمة من `search.js`/`search.css` | السيرفر لم يعد يخزّن CSS/JS (`no-cache`)، ورقم الإصدار `?v=` يرتفع مع كل تغيير — ويمكنك دائماً `Ctrl+F5` |

## 6) التخزين المؤقت (لماذا لا يظهر التحديث أحياناً؟)

| الطبقة | السلوك |
|---|---|
| صفحات HTML | `no-cache` — تُعاد دائماً |
| CSS و JS | `no-cache` — **لا تُخزَّن** (سابقاً كانت `max-age=3600` فتظهر نسخة قديمة ساعةً كاملة) |
| `sw.js` (عامل الخدمة) | الشبكة أولاً لملفات الكود، والكاش بديل عند الانقطاع فقط |
| الصور والخطوط | الكاش أولاً (لا تتغيّر عملياً) |

رقم الإصدار في الرابط (`assets/js/search.js?v=1.1.0`) يرتفع مع كل تغيير جوهري في الملف،
فيستبدل المتصفح النسخة المحفوظة فوراً دون أي تدخل منك.

## 7) الملفات

| الملف | الوظيفة |
|---|---|
| `search.html` | الصفحة (RTL، Cairo، Midnight Gold) |
| `assets/css/search.css` | التصميم: شبكة النتائج، البطاقات، نافذة التشغيل |
| `assets/js/search.js` | البحث، العرض، الاستخراج، النسخ، إنشاء الغرفة |
| `java-server/src/com/watchtogether/SearchResolver.java` | نقطة `/api/search` |
| `java-server/src/com/watchtogether/Main.java` | تسجيل المسار + سطر في اللافتة |

الملفات المعدّلة للربط: `index.html` (زر البحث)، `assets/js/site.js`
(لوحة الأوامر)، `sw.js` (التخزين المؤقت دون اتصال)،
`assets/css/home.css` (شريط سفلي يتكيّف مع 5 عناصر).
