# 📸 وسائط الغرفة — إرسال الصور والفيديو (3.1.1)

ميزة جديدة في دردشة الغرفة: ترفق صورة أو فيديو، فيُرفع إلى **موقع تخزين مجاني**،
ثم يُعرض المحتوى داخل المحادثة **من الرابط الذي يعيده موقع الرفع**، ويُخزَّن ذلك الرابط
في **قاعدة البيانات** مع الرسالة.

---

## ✨ ما الذي يظهر للمستخدم

| | |
|---|---|
| **زر الإرفاق** | أيقونة مشبك في صندوق الكتابة (بحلقة تدرّج متوهّجة عند المرور). |
| **ثلاث طرق للإرفاق** | اختيار من الجهاز · **إفلات** الملفات فوق صندوق الرسائل · **لصق** من الحافظة. |
| **شريط المرفقات** | بطاقات مصغّرة فوق خانة الكتابة: معاينة الصورة، الاسم، الحجم، **شريط تقدّم** حيّ، وزر إزالة. |
| **بطاقة الوسائط** | داخل الرسالة: معاينة احترافية **تملأ عرض صندوق الرسالة (6/6)** مع الحفاظ على نسبة الصورة الأصلية (أفقية/عمودية/مربعة) بلا قصّ مخلّ، أو مشغّل فيديو بشارة «فيديو»، وأدوات عائمة (عرض كاملة · فتح · تنزيل). |
| **العارض المكبّر** | عند الضغط على المعاينة تفتح الصورة أو الفيديو بالحجم الكامل بلا قصّ في نافذة بخلفية ضبابية. النقر على الصورة يبدّل بين **ملء الشاشة** و**الحجم الحقيقي 100%** (يُعاد رسم الصورة بالبكسل فلا تتشوّه)، مع تكبير تدريجي (عجلة الفأرة، إصبعان باللمس، أزرار ±) وسحب/تمرير داخل الصورة الكبيرة، والتنقّل بين وسائط المحادثة، والتنزيل، والإغلاق بـ Esc أو النقر بالخلفية. |
| **رد/تفاعل** | رسالة الوسائط تُردّ عليها وتُتفاعَل معها مثل أي رسالة (اقتباسها يذكر «صورة» أو «فيديو»). |

## 🗄️ أين يُحفظ الرابط في قاعدة البيانات

الرسالة تُخزَّن في `public.messages` كما هي، **ومعها رابط الوسائط**:

| العمود | المحتوى |
|---|---|
| `body` | نص الرسالة + غلاف JSON يحمل الرابط (يعمل مع أي جدول قديم بلا ترقية) |
| `media_url` | رابط الملف كما أعادته مواقع التخزين المجانية (مثال: `https://files.catbox.moe/abc.png`) |
| `media_type` | `image` أو `video` |
| `media_meta` | تفاصيل إضافية (الاسم، الحجم، الأبعاد، المدة) بصيغة JSON |

> **ملاحظة:** حتى لو نُفِّذ المخطط الجديد، تعمل الوسائط **بدون**ه — لأن الرابط داخل غلاف
> الرسالة (نفس فكرة الردود والتعديلات). الأعمدة تجعل الاستعلام与分析 أسهل.

### التفعيل على مشروع Supabase (مرة واحدة)

```bash
# من مجلد watch_together
node tools/sbctl.mjs sql --media        # يطبع الملف 08-room-media.sql
```

أو انسخ محتوى [`docs/sql/08-room-media.sql`](../sql/08-room-media.sql) والصقه في
**SQL Editor** ثم Run. الملف آمن للتكرار: لا يحذف رسائل ولا يغيّر جداول أخرى، ويضيف:

1. أعمدة `media_url` / `media_type` / `media_meta` إلى `public.messages`.
2. دلو تخزين عاماً `wt-room-media` (حد 100 م.ب، أنواع صور/فيديو فقط).
3. سياسات كتابة/قراءة: لا يُقبل إلا المسار `rooms/<كود الغرفة>/<وقت>-<رمز>.<امتداد>`.

المشاريع الجديدة (بعد `01-bootstrap.sql`) تحتوي كل ذلك أصلاً.

## 🌍 مواقع التخزين المجانية (سلسلة بدائل)

الملف يُرفع أولاً إلى **الموقع المضمون: Supabase Storage داخل مشروعك** (دائم وسريع)،
وإن فشل ينتقل إلى **أول مزوّد عام ينجح**، فلا يتعطّل الإرسال:

| # | المزوّد | المدة | ملاحظات |
|---|---------|-------|---------|
| 1 | **Supabase Storage** | دائم | ✅ **الموقع المضمون** — داخل مشروعك، مجاني وسريع ولا يحتاج مفتاحاً إضافياً. |
| 2 | **Catbox** (`catbox.moe`) | دائم | موقع مجاني عام، حتى 200 م.ب — أحياناً يتعطّل فيُجرَّب التالي. |
| 3 | **Litterbox** (`litterbox.catbox.moe`) | **72 ساعة** | موقع موثوق يقبل بلا حساب (حتى 1 غ.ب) ويقدّم الملف مباشرة. |
| 4 | **Tmpfiles** (`tmpfiles.org`) | **7 أيام** | موقع مجاني (حتى 100 م.ب) والرابط المباشر `/dl/` يعرض الملف. |
| 5 | **Uguu** (`uguu.se`) | **مؤقّت** (ساعات) | آخر حل في السلسلة — تظهر عليه ملاحظة «مؤقّت». |

### التخصيص (اختياري)

في [`assets/js/config.js`](../assets/js/config.js):

```js
media: {
  enabled: true,
  maxImageMB: 12,          /* أقصى حجم للصورة */
  maxVideoMB: 80,          /* أقصى حجم للفيديو */
  maxPerMessage: 4,        /* أقصى عدد ملفات في رسالة واحدة */
  supabaseBucket: 'wt-room-media',
  providers: ['supabase', 'catbox', 'litterbox', 'tmpfiles', 'uguu']   /* الترتيب = أولوية المحاولة */
}
```

لإضافة مزوّدك الخاص: أضف دالةً في `PROVIDERS` داخل
[`assets/js/media.js`](../assets/js/media.js) ترجع الرابط بعد الرفع، ثم ضع اسمه في `providers`.

## 🔒 الأمان

- **نوع المحتوى**: صور (jpeg/png/webp/gif/avif/bmp) وفيديو (mp4/webm/mov/mkv/ogv/3gp) فقط.
- **الحجم**: 12 م.ب للصورة و80 م.ب للفيديو (قابلة للتعديل).
- **الرابط**: يُقبل `http/https` فقط، وروابط `javascript:` أو التي تحمل بيانات دخول تُرفض.
- **الغلاف**: يُقصّ النص تلقائياً حتى لا يتجاوز 1000 محرف (حد التخزين في سيرفر Java وSupabase).
- **الملفات المرفوعة**: عامة (كأي رابط صورة على الإنترنت)؛ يمكن حذفها من لوحة Supabase.
