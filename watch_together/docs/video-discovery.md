# استخراج رابط الفيديو الاختياري

أُزيلت ميزة تصفّح المواقع في 2.7.0. الرابط القديم `discover.html` يعيد إلى الرئيسية، ولا توجد بطاقات مواقع أو بحث Google أو عارض داخل الصفحة.

## التشغيل

- YouTube يعمل بالمشغّل الموجود دون استخراج أو API إضافي.
- MP4 وWebM وHLS المباشرة تتجاوز الوسيط.
- روابط الصفحات تُرسل إلى `POST /api/resolve` على نفس الخادم. تظهر نافذة انتظار قابلة للإلغاء. يُنشأ رمز الغرفة بعد نجاح الطلب فقط، ويبقى اسم الغرفة الذي كتبه المستخدم كما هو.
- لا نراقب تبويب موقع خارجي؛ انسخ رابط الفيديو والصقه ثم اضغط إنشاء الغرفة. هذا قيد متصفح وليس وظيفة مفقودة من API.

## إعداد الوسيط

اختيرت خدمة ذاتية الاستضافة تعتمد على مشروع yt-dlp بدلاً من إرسال الروابط إلى مواقع تحميل مجهولة أو وضع مفاتيح في المتصفح.

المتطلبات: JDK 11+ وPython 3 مدعوم من الإصدار الحالي من yt-dlp:

```sh
python3 -m pip install --upgrade yt-dlp
cd watch_together/java-server
./build.sh
./run.sh
```

يمكن تحديد مفسّر Python عبر متغير `WT_PYTHON` (مسار الملف التنفيذي فقط). لا ملفات Cookies ولا تخطي DRM ولا تنزيل الفيديو إلى الخادم. الاختيار يطلب صيغة واحدة تشمل الصوت والصورة لتجنب إرجاع فيديو صامت يحتاج دمجاً. حد الانتظار 40 ثانية، عمليتا استخراج متزامنتان، وحد عام 12 طلباً في الدقيقة لكل عملية خادم. أخطاء الاستخراج لا تعرض تفاصيل الخادم أو مخرجات الأداة.

الاستضافة الثابتة/Supabase وحدها لا تشغّل هذه النقطة؛ تحتاج خادم Java، ويمكن للغرف الاستمرار باستخدام النقل المهيأ حالياً. عند استخدام reverse proxy مرّر `/api/resolve` إلى Java عبر نفس نطاق الصفحة واضبط مهلة تتجاوز 45 ثانية. لا حاجة إلى مفاتيح سرية.

## حدود وأمان النشر

- قائمة نطاقات المصدر محددة في `VideoResolver.java`؛ إزالة دليل المواقع لا تغيّر قيود الوسيط.
- HTTPS فقط، رفض بيانات الدخول والمنافذ غير القياسية وعناوين DNS المحلية عند الإدخال، تعطيل المستخرج العام وإعدادات yt-dlp المحلية، حد لحجم الطلب والنتيجة وعدم مشاركة الخدمة عبر CORS.
- **قبل إتاحتها للعامة:** شغّل الاستخراج بحساب نظام محدود أو حاوية، واضبط جدار خروج يمنع الشبكات الخاصة وloopback وlink-local وواجهات metadata عبر IPv4 وIPv6. فحص عنوان البداية لا يمنع وحده DNS rebinding أو انتقال المستخرج إلى عناوين أخرى. ضع rate limiting إضافياً أمام الخدمة حسب المستخدم/IP؛ الحد العام ليس نظام مكافحة إساءة متكاملاً.
- الروابط الموقعة مؤقتة وقد ترتبط بعنوان IP أو تحتاج Cookies/ترويسات. لا يوجد proxy للفيديو ولا تجديد تلقائي للرابط في هذا الإصدار؛ إن انتهى، استخرج الرابط مجدداً. بعض المصادر تمنع تشغيل HLS بسبب CORS. نجاح الاستخراج لا يضمن المشاهدة لدى جميع المشاركين.
- التشغيل التلقائي بصوت قد يحتاج ضغطة من المستخدم بسبب سياسة المتصفح.
- استخدم فقط المحتوى المسموح بمشاهدته ومشاركته. دعم المواقع يتغير، ويجب تحديث yt-dlp واختبار روابط عامة حقيقية عند النشر.
