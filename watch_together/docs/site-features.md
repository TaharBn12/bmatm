# طبقة الموقع الاحترافية — ميزات لكل الصفحات

هذه الطبقة تضيف تجربة موحّدة «من مستوى المنتجات الاحترافية» إلى **كل** صفحات
WatchTogether (الغرف · الغرفة · الحساب · الملف · الأصدقاء · الرسائل)، **بلا أي
مكتبة خارجية، وبلا تغيير في مخطط قاعدة البيانات، وبلا لمس مفاتيح Supabase**.

| الملف | الدور |
|-------|-------|
| `assets/js/prefs.js` | يُحمَّل في `<head>` قبل CSS: يطبّق اللون/الحركة/التباين فوراً بلا وميض |
| `assets/js/site.js` | الطبقة الكاملة: لوحة الأوامر، مركز التحكم، الاختصارات، مؤشر الشبكة، شريط التقدّم، تثبيت التطبيق |
| `assets/css/site.css` | تصميم الطبقة على لوحة Midnight Gold، وسمات التفضيلات، والجوال |
| `manifest.webmanifest` + `assets/icons/` | تثبيت الموقع كتطبيق (PWA) بأيقونات PNG أصلية |
| `sw.js` + `offline.html` | عمل دون اتصال: صفحة واضحة بدل خطأ المتصفح، والشبكة أولاً دائماً |
| `docs/tests/site-features.mjs` | اختبارات آلية بلا اعتماديات لهذه الطبقة |

---

## 1) لوحة الأوامر — مساحة عمل موحّدة لكل صفحة

`Ctrl + K` (أو `⌘ K`) في أي صفحة، أو من زر «مركز التحكم».

- **بحث عربي ذكي:** يوحّد الهمزات (أ/إ/آ → ا) والتاء المربوطة (ة → ه) والياء
  (ى → ي)، ويحذف التشكيل والتطويل، ويرتّب النتائج: العنوان أولاً ثم الكلمات المفتاحية.
- **أوامر السياق:** كل صفحة تضيف أوامرها الحقيقية فقط:
  - الغرف: إضافة غرفة، تحديث القائمة، ودخول مباشر إلى أي غرفة معروضة حالياً.
  - الغرفة: نسخ رابط الغرفة، رمز QR، قائمة التشغيل، المشاركون، تشخيص الاتصال، مغادرة.
  - الأصدقاء: البحث، الطلبات الواردة، الأصدقاء، المحظورون.
  - الرسائل: محادثة جديدة، دعوة إلى غرفة، البحث في المحادثات.
  - الملف: تعديل الملف، مشاركة الملف.
  - الحساب: التبديل بين تبويبي الدخول والإنشاء.
- **التنقّل العام:** الغرف · ملفي · الأصدقاء · الرسائل · الحساب (تُخفى الصفحة الحالية).
- **دخول سريع بكود غرفة:** اكتب كوداً مثل `AB12CD` فيظهر أمر «الدخول إلى الغرفة».
- **الأوامر الأخيرة:** تُحفظ محلياً (4 كحد أقصى) وتظهر أولاً.
- **وصولية كاملة:** `role="combobox"` + `role="listbox"` + `aria-activedescendant`،
  الأسهم للتنقّل، `Enter` للتشغيل، `Esc` للإغلاق، وحصر التركيز داخل اللوحة.

## 2) مركز التحكم — تفضيلات لكل جهاز

`Alt + S` أو من لوحة الأوامر. كل شيء يُحفظ في `localStorage` تحت `wt:prefs` فقط:

- **أربعة ألوان للموقع:** ذهبي (الافتراضي) · نعناعي · وردي · سماوي — تنتقل معك بين الصفحات.
- **تقليل الحركة:** يوقف الحركات والتدرجات (ويحترم إعداد النظام تلقائياً).
- **تباين عالٍ:** نص أوضح وحدود أقوى وروابط مسطّرة — لقراءة مريحة.
- **واجهة مضغوطة:** مساحات أقل لمحتوى أكثر على الشاشات الصغيرة.
- **تثبيت التطبيق** (حين يسمح المتصفح) · **مشاركة الصفحة** · **اختصارات لوحة المفاتيح**.
- **إعادة ضبط:** تعيد المظهر الافتراضي فقط، ولا تمسّ الحساب ولا الرسائل ولا الغرف.

## 3) اختصارات لوحة المفاتيح

| الاختصار | الوظيفة |
|----------|---------|
| `Ctrl/⌘ + K` | لوحة الأوامر |
| `/` | البحث في الصفحة، أو لوحة الأوامر إن لم يوجد حقل بحث |
| `G` ثم `H / P / F / M` | الغرف · ملفي · الأصدقاء · الرسائل |
| `Alt + S` | مركز التحكم |
| `?` | قائمة الاختصارات |
| `Esc` | إغلاق أي نافذة |

الاختصارات لا تعمل داخل حقول الكتابة، ولا تتعارض مع اختصارات الغرفة القائمة
(المسافة، الأسهم، `D`، `C`). شريط الاختصارات في الغرفة لم يُلمس.

## 4) مؤشر حالة الشبكة

شريط صغير أعلى الشاشة يظهر عند الانقطاع («ستُستأنف المزامنة تلقائياً») ثم يتحوّل
إلى تأكيد أخضر عند عودة الاتصال. يعتمد على أحداث `online/offline` فقط — لا طلبات شبكة إضافية.

## 5) شريط تقدّم التنقّل وزر الصعود

- شريط 3px أعلى الشاشة يظهر عند فتح أي صفحة داخلية، فيبدو التنقّل فورياً.
- زر «إلى الأعلى» يظهر بعد التمرير، ويحترم «تقليل الحركة».

## 6) تطبيق ويب قابل للتثبيت (PWA)

- `manifest.webmanifest`: اسم عربي، اتجاه RTL، `standalone`، اختصارات إلى
  الغرف/الأصدقاء/الرسائل، وأيقونات 192 و512 وأيقونة maskable و`apple-touch-icon`.
- **لا يُسجَّل service worker في `localhost` افتراضياً** (حتى لا ترى نسخة قديمة أثناء
  التطوير). لتجربته محلياً افتح `?sw=1`، ولتعطيله استخدم `?nosw=1`.
- التحديثات تصل فوراً: الصفحات `network-first`، والأصول `?v=` تُخزَّن بمفتاحها الكامل.

## 7) العمل دون اتصال

`sw.js` يخزّن هيكل الموقع (6 صفحات + CSS/JS + الأيقونات) في الكاش، وعند انقطاع
الشبكة تُعرض `offline.html` (أو آخر نسخة من الصفحة) مع زر إعادة المحاولة وعودة
تلقائية حين تتصل الشبكة.

**لا يُخزَّن أبداً:** أي طلب غير `GET`، أو أي طلب إلى نطاق آخر (Supabase/الخطوط/الرفع)،
ولا `docs/` ولا ملفات `.sql/.mjs`.

## 8) اللمسات الاحترافية العامة

- **صفحات بلا 404 صامت:** كل روابط الصفحات الداخلية مُتحقَّق منها آلياً.
- **بيانات وصفية لكل صفحة:** `description` وOG/Twitter و`color-scheme: dark`
  و`apple-touch-icon` حقيقي بدل data-URI.
- **رابط التخطّي:** يظهر عند أول `Tab` لمن يستخدم لوحة المفاتيح (حيث لا يوجد رابط تخطٍّ أصلاً).
- **حدّ أخطاء هادئ:** إشعار واحد كحد أقصى كل 20 ثانية عند خطأ غير متوقّع، بلا رسائل تقنية.
- **`.htaccess`:** نوع MIME الصحيح لـ`.webmanifest` ومنع تخزين `sw.js`.
- **احترام `prefers-reduced-motion`** و`prefers-color-scheme` (المظهر داكن دائماً).

## 9) الاختبارات

```bash
cd watch_together
node docs/tests/site-features.mjs     # 123 فحصاً: الربط، التفضيلات، الأوامر، manifest، sw
npm test                              # كل الاختبارات الحالية
```

## 10) ملاحظات نشر

- لا خطوة SQL جديدة، ولا متغيّرات بيئة جديدة.
- الخدمة العاملة تحتاج **HTTPS** (أو `localhost`) — أي استضافة عادية تعمل.
- بعد رفع الملفات، افتح الصفحة مرة واحدة ليُسجَّل `sw.js`، ثم ستظهر نصوص التحديث
  عند أول زيارة بعد أي إصدار جديد.
