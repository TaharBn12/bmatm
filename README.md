### WatchTogether — باختصار

- **رئيسية شخصية مختصرة:** بطاقات الغرف، وزر عائم **+ / ×** لإظهار/إخفاء صندوق إضافة غرفة، بلا نصوص دعائية أو دليل مواقع.
- **مساحة أعضاء أصلية (3.0):** ملف كامل وصورة من الهاتف مع قصّ/تكبير/تدوير، بصمة مشاهدة وألوان/أغلفة شخصية، بحث وصداقة/حظر، وصفحة مراسلة خاصة للأصدقاء مع مسودات وإيصالات اختيارية ودعوات غرف.
- **التفعيل الاجتماعي:** نفّذ [`07-social.sql`](watch_together/docs/sql/07-social.sql) بعد مخطط الغرف الحالي؛ لا تحذف بياناتك. [التفاصيل والخصوصية والاختبارات](watch_together/docs/social.md). لم تُطبّق الترقية على مشروع Supabase عن بُعد تلقائيًا.
- **📸 وسائط الغرفة (3.1.1):** زر إرفاق في الدردشة (أو إفلات/لصق) يرفع الصور والفيديو إلى **الموقع المضمون Supabase Storage** (← Catbox ← Litterbox ← Tmpfiles ← Uguu بسلسلة بدائل تلقائية)، ثم يعرضها من **رابط موقع الرفع** ويخزّن الرابط في قاعدة البيانات (`messages.media_url`). [التفاصيل](watch_together/docs/media.md).
- **كروت الغرف:** غلاف فيديو صامت مدته 5 ثوانٍ على اليسار، والاسم على اليمين، و5 افتارات للمنضمين حاليًا ثم عدد البقية مثل **+6**.
- **الدخول:** صاحب الحساب يدخل الغرفة مباشرة؛ الضيف يكتب اسمه. صفحة الغرفة: مشغّل وشريط تقدم، ثم الرسائل مباشرة، والمشاركون في القائمة الجانبية.
- **مزامنة حساسة جداً:** بثّ فوري عند كل إجراء، **والمنشئ والمنظّمون يستطيعون التحكم**،
  ورفع الحالة إلى قاعدة البيانات **كل 5 ثوانٍ**، و**حفظ تلقائي عند خروج آخر مستخدم**.
- **التحاق المتأخرين:** من يدخل بعد بدء العرض يأخذ الوقت الحالي المحسوب — لا يبدأ من الصفر.
- **أيقونات SVG** للواجهة؛ الإيموجي يُرسل كرسالة عادية، ويمكن التفاعل مع رسالة محددة بإيموجي وعدّاد مع التبديل والإلغاء.
- **يعمل على استضافة عادية** (Supabase) أو عبر **سيرفر Java** مرفق (JDK فقط، بدون مكتبات).
- **تشخيص الاتصال في الغرفة:** زر «تشخيص» يشرح السبب والحل بدل رسالة «تعذّر الاتصال» الغامضة.
- **أداة سيرفر جديد:** `node watch_together/tools/sbctl.mjs create` ينشئ مشروع Supabase جديداً
  وينفّذ المخطط وربطه بالموقع بأمر واحد.
- **اختبارات آلية للغرفة والمشغّل**: `cd watch_together && npm test` (بلا اعتماديات)،
  واختبارات PostgreSQL فعلية `npm run test:social:db` وChromium `npm run test:social:browser` و`npm run test:browser` بعد تثبيت اعتماديات التطوير والمتصفح.

```bash
cd watch_together/java-server && ./build.sh && ./run.sh   # → http://localhost:8080
```
