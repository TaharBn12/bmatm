### WatchTogether — باختصار

- **صفحتان:** رئيسية (إضافة رابط المشاهدة + إنشاء غرفة) وغرفة (مشغّل متزامن + دردشة أسفل الصفحة).
- **دخول بالاسم:** من يفتح رابط الغرفة يُطلب منه إدخال اسمه قبل الدخول.
- **مزامنة بكل الحالات:** تشغيل/إيقاف/تقديم/تأخير/تغيير الفيديو/انحراف الوقت/غياب المضيف.
- **يعمل على استضافة عادية** (Supabase Realtime) أو عبر **سيرفر Java** مرفق (JDK فقط، بدون مكتبات).

```bash
cd watch_together/java-server && ./build.sh && ./run.sh   # → http://localhost:8080
```
